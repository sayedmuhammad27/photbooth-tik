DIREKTORI FONT MECAROS - PHOTOBOOTH TIK
=========================================
Direktori ini disiapkan untuk file font resmi Mecaros.

Jika Anda memiliki file font resmi Mecaros:
1. Salin file font dengan nama:
   - Mecaros.woff2 (direkomendasikan untuk web)
   - ATAU Mecaros.ttf / Mecaros.otf
2. Letakkan file tersebut di direktori ini: public/fonts/
3. Browser akan otomatis memuat file font Mecaros via @font-face yang sudah dideklarasikan pada pixel-core.css.

Jika file font resmi belum dimasukkan:
Aplikasi otomatis menggunakan font fallback modern (Syne, Cinzel, Playfair Display) dengan gaya visual kreatif agensi tebal yang selaras.
